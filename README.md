# NAVITO

A premium, luxury e-commerce experience tailored for the Moroccan market.

## Project Overview
NAVITO is designed to provide a world-class shopping experience with a focus on luxury aesthetics, high performance, and localized support.

## Key Features
- **Multi-language Support**: Full support for Arabic and English with RTL/LTR layouts.
- **Premium UI/UX**: Modern, responsive design with luxury-themed components.
- **Order Tracking**: Seamless order tracking system for customers.
- **Admin Dashboard**: Comprehensive management interface for products and sales.
- **Localized Marketing**: Integrated tools for the Moroccan market (WhatsApp integration, COD optimization).

## Tech Stack
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+).
- **Backend**: Node.js, Express.
- **Database**: MongoDB (Mongoose).
- **Integrations**: Firebase for authentication/storage, WhatsApp API.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yassine567990/NAVITO.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
